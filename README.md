# Zeam-Launcher

Zeam-Launcher is a minimalistic launcher for Android phones. This app is no longer under development.

## Installation

To install Zeam-Launcher, follow these steps:

1. Clone the repository: `git clone https://github.com/samuelcaldas/Zeam-Launcher.git`
2. Navigate to the repository: `cd Zeam-Launcher`
3. Follow the instructions in the documentation to build and install.
